Getting started

A home for your next idea.

Use the desktop app without a terminal, or bring the workflow into your existing AI coding host as a plugin.

Install the desktop app

Open GitHub Releases and choose the installer for your computer. Download from a published release rather than a workflow test build.

PlatformDownloadInstall
macOS (Apple silicon or Intel)Author-Studio-<version>-universal.dmgOpen the disk image and drag Author Studio to Applications.
Windows 10 or 11Author-Studio-Setup-<version>.exeRun the installer. It installs for your account.
Ubuntu or DebianAuthor-Studio-<version>-amd64.debOpen with your software installer.
Other LinuxAuthor-Studio-<version>-x86_64.AppImageMake the file executable, then open it.

Mac releases are signed and notarized. Windows installers are not yet signed: SmartScreen may show a warning. Verify that you downloaded the release from this repository before choosing More info → Run anyway.

Connect a model

On first launch, add a connection for Claude, GPT, a local/network server, or Apple Intelligence. Use Test connection before saving. Connections can be changed later in Settings.

Claude and GPT require your own API key and bill usage separately. Apple Intelligence requires Apple silicon, macOS 26 or later, and Apple Intelligence enabled. See Models & privacy for requirements and tradeoffs.

Start a project

  1. Create a project with a story idea. Include genre, tone, audience, and form if you know them.
  2. Develop a creative brief, then choose research, setting, story planning, writing, or revision.
  3. When review is required, approve the proposal, request changes, or reject it. Choose the next step when you are ready.

You can plan without drafting. A short story or flash piece can use the same workflow as a novel; agree on its length and treat the first numbered unit as the whole piece.

Prefer a plugin?

The plugin uses the model and tools supplied by your host. It does not connect directly to model APIs or require its own API key.

GitHub Copilot CLI

copilot plugin install thorrsson/author-studio

Start a new session, confirm discovery with /skills list, then try:

/author-studio start A historical mystery in a seaside town
/author-studio world
/author-studio plot
/author-studio draft 1

Use the skill name in your host's picker if your version namespaces it differently.

Claude Code

claude plugin marketplace add thorrsson/author-studio
claude plugin install author-studio@author-studio-marketplace

Start a new session and use the plugin-qualified skill name:

/author-studio:author-studio start A literary family saga
/author-studio:author-studio world
/author-studio:author-studio plot
/author-studio:author-studio draft 1

The repeated name is intentional: Claude Code uses /plugin-name:skill-name.

Local checkout and other hosts

From a stable local checkout, run copilot plugin marketplace add . or claude plugin marketplace add ., then install author-studio@author-studio-marketplace. Copilot CLI 1.0.89 does not accept copilot plugin install ..

Other Agent Skill-compatible hosts can load the complete skills/author-studio/ directory, including its resources. Installation and invocation depend on the host. A chat app is not automatically plugin-compatible. See the repository installation guide for details.

Save before you close

Desktop: projects save on your computer. Use History → Back up project for a complete portable copy. Restore with File → Open Backup or State File.

Plugin: state lives in the conversation, not in an automatic cross-session store. Ask for a snapshot and accepted artifacts to be exported, or run state and copy the snapshot. In a new session, supply the snapshot and relevant manuscript/lore files and ask to resume.

A state snapshot contains the story bible and progress, not the full manuscript. Keep desktop backups or exported manuscript files as well.

Updates and help

Installed Mac, Windows, and Linux AppImage builds check for stable updates. The app asks before downloading and before restarting to install. Find Check for Updates in the Author Studio menu on Mac or Help on Windows/Linux. Older versions without the updater, Debian packages, and source builds need a manual download.

For troubleshooting or a feature request, open a GitHub issue. Never include API keys or private manuscript text in a public report.
